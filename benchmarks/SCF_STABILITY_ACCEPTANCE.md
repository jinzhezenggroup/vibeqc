# Acceptance criteria

- Normal-convergence results retain every raw repeat and iteration branch.
- Branch-unstable results are explicitly classified as inconclusive for a headline cross-engine ratio.
- Ordinary pooled medians remain diagnostic only when iteration work differs.
- Fixed-work measurements, once implemented, do not replace converged numerical gates.
- A headline SCF performance ratio requires one stable shared iteration branch or an explicitly fixed amount of SCF work.
