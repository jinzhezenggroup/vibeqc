# Glossary

**AO** — atomic-orbital basis function.
**Basis set** — finite functions used to represent the electronic problem.
**DFT** — density-functional theory.
**ECP** — effective core potential.
**Fock operator** — effective one-electron operator used in SCF.
**Force** — negative nuclear derivative of energy.
**Gradient** — nuclear derivative of energy.
**Hessian** — matrix of second nuclear derivatives.
**HF** — Hartree-Fock.
**MO** — molecular orbital.
**Multiplicity** — `2S + 1`.
**RHF/UHF** — restricted/unrestricted Hartree-Fock.
**RKS/UKS** — restricted/unrestricted Kohn-Sham DFT.
**SCF** — self-consistent field iteration.
**XC** — exchange-correlation.
