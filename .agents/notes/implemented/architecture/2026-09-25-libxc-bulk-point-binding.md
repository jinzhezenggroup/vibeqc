# Decision: Bind imported Libxc point programs by exact artifact identity

Status: implemented
Date: 2026-09-25

## Problem

Bulk Libxc import already produces a projected runtime graph, while the native
semilocal integrator consumes the compact rho/sigma/tau point ABI.  Crossing
that boundary without preserving both identities would make it possible to
execute generated bytes whose imported capability or projected mathematics no
longer matches the qualification evidence attached by later stages.

Tau-only meta-GGAs also need to stay on the projected rho/sigma/tau feature set;
reintroducing dead Laplacian inputs at AOT emission would create a second ABI
identity and invalidate the projection contract.

## Decision

Bind a CPU semilocal point program to three independent identities: the imported
capability identity, the projected point-expression identity, and the exact AOT
emission identity/source hash.  The binding additionally records domain version
and compact feature layout.  It is executable plumbing only and does not grant
production-domain, molecular-SCF, or public-method capability.

Emit the already-projected graph through the shared scalar lowerer.  Map
rho/sigma derivatives to the native Cartesian-gradient pullback and retain the
existing vtau/2 weak-form convention for tau.  Reject non-polarized, partial
E/vxc, unsupported feature layouts, and non-positive domain versions.

## Rejected alternatives

- Re-run the unprojected bulk AOT path at this boundary: rejected because it can
  reintroduce dead Laplacian inputs and create a different executable ABI.
- Treat source generation or successful compilation as production admission:
  rejected because later domain and molecular-SCF qualification remain separate.
- Bind only by a human-readable functional name: rejected because a name does
  not identify imported source, projected mathematics, or emitted bytes.

## Invariants

- Capability, projected expression, and emitted-artifact identities remain
  separately inspectable and all contribute to the binding identity.
- The compact native layouts remain rho=1, rho/sigma=7, rho/sigma/tau=15.
- Generated source does not import the public runtime or probe devices.
- This bridge never manufactures production or public-method evidence.
- Tau enters the native weak-form coefficient as vtau/2.

## Evidence

- `tests/python/test_bulk_point_program.py` covers non-curated LDA/GGA/MGGA
  layouts, identity binding, fail-closed inputs, and compiles/executes a
  GGA_X_PBE_SOL adapter against the projected Graph evaluator.
- PR #1276 leaves production-domain and molecular-SCF admission to #1120 and
  #1234 rather than widening public capability.

## Consequences

Later qualification can refer to one exact executable binding without conflating
import, expression, and binary-source identities.  The CPU point bridge remains
narrow until independent production-domain and molecular-SCF evidence exists.

## Revisit when

Revisit the binding schema if the native semilocal ABI gains new scientific
ingredients, if unpolarized point programs become a first-class native contract,
or if a compiled-artifact registry can preserve the same identity separation
without this source-level binding object.
